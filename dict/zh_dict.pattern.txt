# System Informer 中文词典 · 通配符模式表
# ===========================================================================
# 给「运行期拼出来的串」用。这类串每次运行内容都不一样（夹着 CPU 百分比、
# 内存用量、对象名……），精确匹配的 zh_dict.txt 永远命中不了它们。
#
# 文件格式与 zh_dict.txt 完全一样：每行「原文<TAB>译文」，# 开头是注释。
# 区别只在原文里可以用通配符：
#
#   *        任意长度（可为空）的片段，并且**捕获**它
#   ?        恰好一个字符，不捕获
#   \* \? \\ 转义，表示字面量
#
# 译文里的占位符：
#   *        依次取「还没被用过的」捕获（第 1 个 * 取捕获 1，以此类推）
#   \1..\9   显式取第 N 个捕获（可以换序、可以重复引用）
#   \\       字面反斜杠
#   没用到的捕获会按顺序追加到译文末尾 —— 宁可译文啰嗦，也不让界面上的
#   数据悄悄消失。
#
# 写模式必须知道的四条：
#   1. * 取**最短**可行片段（不是贪婪）。'*Notes: *' 里第一个 * 只吃到 Notes:
#      之前那一段，不会把整串吞掉。
#   2. 首尾都带 * 等于**子串替换**。
#   3. 顺序有意义：靠前的先匹配。具体的写前面，宽泛的写后面。
#   4. ★ **多行文本不套模式** —— 这是硬限制，不是没做。
#      「进程提示气泡」那种一整串多行文字，行距是 System Informer 按**原文宽度**
#      自己算好再逐行画的。把里面的字段标签换成中文，字宽就变了（"Signer:" 是
#      6 个半角，"签名者：" 是 4 个全角），而它那边并不知道 —— 实测结果是气泡的
#      几行叠在一起、糊成一团。那是**画错**，比不翻译糟糕得多，所以钩子里碰到
#      含换行的文本直接不套模式（见 MatchPatterns 里的说明）。
#      后果：气泡仍是英文，只能靠 zh_dict.txt 精确匹配（而它每次内容都不同，
#      所以实际就是译不了）；它产生的未命中记录由 tools\organize.py 的
#      MISS_DROP_PATTERNS 在合并阶段丢掉，不会污染词典。
#
# 应用方式：反复过所有模式，直到某一遍没有任何改动（最多 4 遍）。
#
# 改完建议跑： python tools\check_pattern.py
# ===========================================================================
